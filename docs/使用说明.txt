标书检查 Lite —— 使用说明
==========================

1. 解压到任意目录，双击「标书检查.exe」。
   没有黑窗口，几秒后浏览器自动打开 http://127.0.0.1:8765/
   如果浏览器没自动打开，手动访问上面的地址即可（端口被占用时会自动换 8766、8767…，
   实际地址写在 lite_data/server.log 里）。
2. 页面上拖入两份文件：
   ① 招标文件 / 磋商文件（PDF 或 Word .docx，PDF 更准）
   ② 投标文件 / 响应文件（PDF 或 Word .docx）
   点「开始检查」。几秒到一分钟出结果，首次解析大文件慢一些，之后有缓存。
3. 结果按"不通过 / 警告 / 待人工 / 通过"筛选，每条都标了招标文件页码和投标文件页码，
   鼠标停在页码上可以看原文摘录。可下载 Markdown 或 JSON 报告。
4. 用完点右上角「退出程序」关闭后台，或者直接关浏览器（后台还在，下次双击会直接打开页面）。

设置（右上角「⚙ 设置」）
- 阿里云百炼 key：识别扫描件（资质证书、安全生产许可证、安B证等）。不填这些条目标为"待人工"。
- LLM key：默认 DeepSeek，填好后点「获取可用模型」选一个（推荐 deepseek-flash，便宜），再点「测试 LLM」。
  不填时需要语义判断的条目标为"待人工"。目前只有施工招标模板有语义判断条目，磋商模板全部是确定性规则。
- key 只保存在本机 lite_data/settings.json，不会发送到别处。
- 「清理解析缓存」只删解析缓存；「清空全部记录」连同上传的文件和报告一起删。

支持的模板（自动识别）
- 福建省房建市政标准施工招标文件（公共资源交易平台，评定分离）
- 福建省政府采购竞争性磋商文件（工程类）
其他格式的文件也能跑，但只输出通用条目，模板置信度会很低，请以人工复核为准。

数据都在 exe 同级的 lite_data 目录：jobs（每次检查的文件与报告）、cache（解析缓存）、
settings.json（key）、server.log（后台日志，出问题时看这里）。删除整个 lite_data 即恢复初始状态。

常见问题
- 双击没反应：等 5 秒再看浏览器；还不行就打开 lite_data/server.log 看报错。
- 页面显示一段英文报错：把那段文字（或 server.log）发给维护者即可定位。
- 杀毒软件拦截：这是打包程序的通病，选"允许运行"即可。
- 不要在压缩包里直接双击 exe，先解压。
